# Stock Price Predictor

This project predicts the **next day's closing price** of a stock (like GOOGL) using the last 5 days of data and additional features (Volume, High, Low, Open).

## 🔍 Features Used
- Closing prices of the last 5 days
- Volume (scaled)
- High, Low, and Open prices of the latest day
